# 데이터베이스 접근 정책

## DEV_DB

- 개발 업무가 있는 구성원은 프로젝트명과 사용 목적을 적어 접근 권한을 신청한다.
- 신청은 HelpDesk의 `ACCESS_REQUEST` 티켓으로 접수되며 상태는 `PENDING`에서 시작한다.
- 승인 전에는 권한이 부여되지 않는다.

## PROD_DB

- 운영 DB 접근은 최소 권한 원칙을 적용한다.
- 운영 장애 대응 등 명확한 업무 사유와 책임자 승인이 필요하다.
- 신청은 `ACCESS_REQUEST` 티켓으로만 접수되며 Agent가 권한을 직접 부여하지 않는다.
- 작업이 끝나면 권한 회수 대상이 된다.
